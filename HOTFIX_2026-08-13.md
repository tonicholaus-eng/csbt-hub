# CSBT Exchange refresh/build hotfix

Fixes the issues reported after the Exchange migration:

1. `snapshot:values` Postgres 21000 / duplicate ON CONFLICT rows
   - Never converts null to zero.
   - Only stores positive market observations.
   - Deduplicates each snapshot by the exact Supabase conflict key.
   - Removes invalid zero-value history rows created by the older script.

2. Canonical item ID collisions
   - Generator now deduplicates by canonical `ID`, not only the literal item name.
   - Punctuation aliases such as `Mr Whiskerpips` / `Mr. Whiskerpips` merge into one item.
   - The record with better GCash data is preferred and missing metadata/values are merged.

3. Expanded Elve helper/unusable records
   - Removes `nan` and Elve helper entries `Add`, `Add Big`, `Add Small`, `Big Add`.
   - Skips rows where both GCash Regular and Elve Regular are unknown.
   - Keeps legitimate known zero-value items in the searchable master database.
   - Validator accepts a known numeric zero as a known source, while still rejecting missing/null-only rows.

4. `ExchangeDemandPulse.tsx` TypeScript build failure
   - Captures the narrowed Supabase client before the nested async loader/realtime callback.
